# Contracts

SubagentStop uses agent_transcript_path, never the parent transcript. A nonblank
last_assistant_message must match a transcript completion after at most about two
seconds of rereads. No aliases are inferred. Only the bound agent can finish a
ready/continue round; duplicate completions do not add usage or iterations.

build next/check recover clean committed work only with completion evidence.
build reconcile observes the same rule. Another same-repository worktree needs
an Owner step answer bound to both paths/HEADs and the current item/build. The
exact command reruns after approval; changed evidence asks again. It never gates
the old spec commits as a substitute for the selected PR work.

Round 2: ValueError during any transcript read is retried inside the same deadline.
Manual ready/continue recovery accepts --verdict without a file only. It reads the
seat's recorded transcript, rejects the recorded completion, and passes that original
transcript through all stop guards, preserving the real completion identifier.

A deleted old worktree appears as missing on the rebind card. The requested tree
still requires configured-repository validation. Old-tree reappearance changes
the approval evidence and requires another answer.
