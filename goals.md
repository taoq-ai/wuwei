# Goals

One block per goal. The plan's items each name the goal they serve.

## G-1
Outcome: WUWEI is developed under WUWEI: every change to this repository goes through a plan item, gates before its PR, and the doors, and every merge (release PRs included) goes through the merge door.
Measure: merged PRs on taoq-ai/wuwei with gates attested at their head (or read as generated by the merge door), over all merged PRs; read with `wuwei report --merged` once the export item lands, unmeasured until then.
Target: 100 percent from the merge of #1064 on; 0 merges "without WUWEI reading its evidence" in the day report from 2026-10-19 on.
Date: 2026-10-23
Priority: 1

## G-2
Outcome: the current release line holds up in real use: bugs found while running WUWEI on itself are fixed before features, and each fix ships in a release.
Measure: open issues labelled bug, plus open bug-shaped issues without the label (#1113, #1129, #1130, #1131, #1132 on 2026-10-18); escapes the retro traces to a gate; days from a bug fix's merge to the release that carries it.
Target: no bug open more than three days; the 2026-10-18 bug sweep released in the next release-please cut; every later fix released within two days of its merge.
Date: 2026-10-23
Priority: 2

## G-3
Outcome: in every repository running WUWEI, each seat runs on the model and reasoning effort its work needs, from one table drawn from Anthropic's model guidance, shipped in the plugin; the planner follows it and may depart with a recorded reason; WUWEI advises and records, never refuses.
Measure: seat.started rows that record the resolved model and requested effort, over all seat launches; departures from the table with a recorded reason, over all departures; per seat x model x effort, fix rounds, blocking findings, escapes and tokens per merged item, as the report prints them.
Target: 100 percent of launches record model and effort from the models-record merge on; after 14 days the report shows outcomes per seat class and model/effort, and the steward's retro either proposes a table change backed by them or records that none is warranted; tokens per merged item fall with no rise in escapes over the same window.
Date: 2026-11-08
Priority: 3

## G-4
Outcome: the feature backlog open on 2026-10-18 is shipped in releases or closed with the owner's ruling, within a revised runtime budget.
Measure: the 2026-10-18 feature issues (#1133, #1120, #1119, #975, #962, #957, #920, #918, #917, #637, #441, #415, #370, #309, #999) still open with neither a release that ships them nor an owner ruling; runtime lines against the revised budget.
Target: 0 such issues; runtime within the revised budget (proposed 3,400) at every merge.
Date: 2026-11-30
Priority: 4
