## Findings
- [high] cli/wuwei/guards.py:90 blocks: yes. Failure: with '`' in punctuation_chars, shlex joins a closing backtick to the operator after it into one token ('`;', '`&&', '`|'), and that token is not in CONTROL. So `` x=`date`; git push --force origin x `` reads as one command whose program is `date`, and it passes. The same shape lets through `gh pr merge 5 --admin`, `wuwei hook Stop` and `rm .wuwei/ledger/x`. Main 5d7157b refuses all four, so this is a regression on an ordinary one-line command. Fix: treat any token made only of the characters ();|&` as a separator. That also closes the `true;(git push ...)` gap that main has too.
- [high] cli/wuwei/guards.py:74 blocks: yes. Failure: when the delimiter is unquoted, bash removes backslash-newline from body lines before it compares them with the delimiter or expands them. The scanner checks the raw text instead. (a) For "cat <<EOF\n$\\\n(git push --force origin x)\nEOF", the scanner sees no `$(` and drops the body, but bash joins the lines into `$(git push ...)` and runs it. Main refuses this input. (b) For "cat <<EOF\nEO\\\nF\ngit push --force origin x\nEOF", bash ends the heredoc at the joined `EOF` and runs the push, while the scanner drops the body until the literal `EOF` line. The same happens with `<<-` and a tab. Fix, fail closed: with an unquoted word, also break when the body holds a backslash-newline, i.e. re.search(r'\$\(|`|\\\n', body[1]).
- [high] cli/wuwei/guards.py:78 blocks: yes. Failure: in "a=( [1<<EOF ]=x )\ngit push --force origin x\nEOF" and in the form where `[` starts a new line inside `a=(`, the `[` follows a space or a newline, so the flag is not set and a heredoc starts. bash parses a word that starts with `[` inside a compound assignment as a subscript (read_token_word, PST_COMPASSIGN), so `<<` is a shift and the push line runs. Main refuses both inputs. This is a sibling of the acceptance shapes `a[1<<EOF ]` and `([`. Fix: also set the flag at an unquoted `=(`.
- [medium] cli/wuwei/guards.py:69 blocks: yes. Failure: the comment rule fires inside `${...}`. Main refuses both. Fix: skip comments only while the flag is unset (elif c == '#' and not expansion and ...), which fails closed.
