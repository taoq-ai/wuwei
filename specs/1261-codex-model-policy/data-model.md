# Data model

Existing models config: role-and-tier string wins over role string, then table. No new config key.

Existing seat.started rows: asked and effort describe requested settings; model describes provider-resolved child model or unmeasured. Native rows additionally name turn_model and turn_effort for the launching parent turn, and fork_policy for the explicitly requested inheritance policy. Missing measurements stay unmeasured. No actual child inheritance is inferred. Existing Claude rows keep their shape.
