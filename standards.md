# Standards

Lines per role. The planner passes each role its lines in the seat brief; a line names the
repository it is about. Dated; a line that catches nothing in 30 days is proposed for removal.

- builder (taoq-ai/wuwei, 2026-10-17): a change under `cli/wuwei/guards.py` or `cli/wuwei/hook.py` follows AGENTS.md "Testing the guards": the route corpus on main and the branch with its sha256, the generated combinatorial probe with its three counts (generated, ran the door program, holes), probe fixtures written by code.
- quality (taoq-ai/wuwei, 2026-10-17): a change to guard parsing is re-probed with the generated combinatorial probe of AGENTS.md "Testing the guards"; a class is added per hole; equivalence or deletability needs the differential probe with 0 differences.
- security (taoq-ai/wuwei, 2026-10-17): a parser rewrite, or a change that makes more commands unreadable, also probes the checks that do not rely on door words (the leak check on network programs, the ask rule for infrastructure commands); a normalisation round probes each path class and working-directory wrapper listed in AGENTS.md "Testing the guards".
- arch (taoq-ai/wuwei, 2026-10-17): a change to `guards.py` or `hook.py` carries the main-versus-head differential over `tests/fixtures/routes.json`, naming each route whose verdict moves.
- goal (taoq-ai/wuwei, 2026-10-17): the probe counts in a PR body (generated, ran, holes) are read from the probe output at the head, never copied from the body.
