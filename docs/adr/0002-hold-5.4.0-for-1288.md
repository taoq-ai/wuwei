# 0002. Hold release 5.4.0 until PR 1288 merges

Date: 2026-11-05
Status: accepted

## Context

Release-please PR #1280 (5.4.0) carried the day's merges #1283, #1284, #1285 and #1287. #1287 is the
compaction re-orientation the owner asked for. PR #1288 (item config-door) had just found that on
main `eval` hid every door for every session. `eval 'git push --force origin main'`, `eval 'gh pr
merge 5'` and a ledger write through `eval` all passed. The planner asked the owner a `one-way:`
question, because a published release cannot be taken back: cut 5.4.0 now, or wait for #1288.

## Decision

The owner answered "Wait for #1288". 5.4.0 is cut only after #1288 merges, so the eval fix ships
with the rest.

## Consequences

- The compaction fix and report masking reach installs later.
- 5.4.0 carries the eval door fix and the seat door on `.wuwei/config.toml` and `.wuwei/plan.json`.
- The installed plugin stays at 5.3.0 until then, and that version drops answers when it records the
  owner's answers.
- Reversing this means cutting 5.4.0 from main without #1288.
