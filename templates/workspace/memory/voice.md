# Owner voice

The owner edits this profile. Agents propose changes with `wuwei voice learn` and
the owner reviews proposals before `wuwei promote`. Keep real examples here in
the workspace, never in the plugin repository.

Each audience may set `- max_length: N`, `- required_prefix: text`, and repeated
`- never: phrase` rules. Register, structure, preferred phrases and redacted
examples may be recorded as ordinary prose below each heading.
