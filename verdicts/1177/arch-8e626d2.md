## Findings
- [medium] cli/wuwei/evidence.py:231 blocks: yes. Failure: the production rule `'prod' in environment.lower()` counts non-production environments. A failing deploy to `preprod`, `pre-prod`, `Pre-Production`, `nonprod`, `non-prod` or `non-production` (and also `productivity-sandbox` and `reproduce`) counts as a production change failure (probe_prod.py at the head: all 8 counted). Pre-production environments are where deploys are expected to fail, so a repository that names one this way trips its error budget and gets every tier raised. Its DORA rate is inflated too. This violates the owner's ruling ("failed production deploys") and is a requirement defect in the classification rule. The recorded assumption only covers the opposite error (a production environment named otherwise). Fix: exclude pre/non-prefixed names or match prod as a leading word, with a test. Or record the false positives under Assumptions and get the owner's acceptance.
- [medium] cli/wuwei/board.py:81 blocks: yes. Failure: on a cold board, `evidence.gaps` reaches `evidence.budget` from up to 8 pool threads at once, and `_cached` (evidence.py:131) has no lock. So every thread reads each production deployment's statuses. Probe at the head: 18 linked PRs and 100 production deploys gave 800 status reads, 16 deployment pages and 983 host calls in total. The same board at main made 167 calls. A single budget read would add about 102. The PR's Assumptions line ("one host call each, cached for a day") is wrong by the pool width. For a repository the size of ai-stacks, with several hundred deploys, one cold board spends thousands of the 5,000 per hour REST quota. Once that quota runs out, every door's evidence read fails. This is an operability regression on the board's host-call budget (#1121, #1161). Fix: warm `evidence.budget(root, repo)` once before the pool in board.compute (one line), or lock the budget read.

That is the issue's own ai-stacks case, and the test expects 0.6 from it. With 5 to 10 merges, the double count alone can move a repository over the 15 percent budget.
