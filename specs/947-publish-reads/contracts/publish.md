# Publish guard contract

A named Vercel read or deployment/environment GET without fields/input returns `(0, '')` without asking the owner. A deployment write returns exit 1 and the existing Owner step card until approved. Config failures retain exit 2. Explicit deny patterns override read exemptions. The Yes description states that only this exact command text is approved and instructs the planner to run it alone. Modified and compound commands need their own approval.

Review follow-up: preview option values are consumed in both spaced and equals forms. More than one operand including a deployment/environment path requires an Owner step card. Header values containing override (case-insensitive) are non-reads on those paths. Host permission denies and owner design wording remain unchanged.
