# Native producer contract

The supported producer writes JSONL under the account-derived default `.codex/sessions` root. The first session_meta, parent collaboration.spawn_agent function_call, JSON-string function_call_output.task_name, child own assistant final_answer, optional later task_complete and own turn_context form the evidence contract.

Hook transport may name the tool spawn_agent or collaborationspawn_agent. The genuine SubagentStop carries session_id, agent_id, agent_type, transcript_path, agent_transcript_path and last_assistant_message. Its UUID maps to canonical path only after matching protected records. An outside root, malformed record, mismatch, inherited final or earlier replay cannot attest.

Native parent agent_message notifications suppress repeated delivery only with the matching author, recipient, exact FINAL_ANSWER frame, body and timestamp. Companion jobs and ordinary owner replies do not satisfy this contract.
